# Smart Wakala — Android app downloads

Smart Wakala is the Agency Services (mobile money) app for agents on the BJP Technologies LMS platform.

## Download
Get the latest version from **[Releases](https://github.com/MussaJabir/wakala-app-releases/releases/latest)**
and download the `.apk` file.

## Install (Android)
1. Download the `.apk` on your Android phone.
2. Open it. If asked, allow your browser or file app to **install unknown apps**.
3. Tap **Install**, then open **Smart Wakala**.
4. Sign in to your company, or create a new one.
